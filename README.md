# Rapid OBD

Безкоштовний вебзастосунок для діагностики Škoda Rapid 1.6 TDI через адаптер ELM327 з Bluetooth LE: коди несправностей, параметри двигуна, витрата пального, автоскан блоків VAG і резервна копія параметрів (лише читання).

**Відкрити:** https://serheyomelchenkodopomoga-eng.github.io/rapid-obd/

> **Застосунок безоплатний і надається «як є». Ви використовуєте його на власний ризик.**
> Перед першим використанням потрібно прийняти [Умови використання](TERMS.md).
> Без прийняття Умов застосунок не працює.
