# Rapid OBD

Безкоштовний вебзастосунок для OBD-діагностики автомобілів через адаптер ELM327 з Bluetooth LE. Автомобілі групи VAG (Škoda, Volkswagen, Audi, SEAT/CUPRA) розпізнаються автоматично за VIN і блоком двигуна: автоскан блоків, коди несправностей, параметри двигуна, витрата пального, резервна копія параметрів (лише читання). Інші автомобілі працюють через стандартний OBD-II.

**Відкрити:** https://serheyomelchenkodopomoga-eng.github.io/rapid-obd/

> **Застосунок безоплатний і надається «як є». Ви використовуєте його на власний ризик.**
> Перед першим використанням потрібно прийняти [Умови використання](TERMS.md).
> Без прийняття Умов застосунок не працює.
